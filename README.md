# Timeline Builder

날짜 기반 이벤트를 시각적인 타임라인으로 만들고 관리하는 정적 웹앱입니다. 빌드 도구나 서버 없이 브라우저만으로 동작합니다.

## 주요 기능

- **이벤트 관리**: 제목, 시작일/종료일(선택), 카테고리, 색상, 설명을 입력해 이벤트를 추가·수정·삭제
- **타임라인 뷰**: 날짜순으로 배치된 카드형 타임라인, 겹치는 이벤트는 자동으로 여러 줄에 배치
- **목록 뷰**: 표 형태로 모든 이벤트를 한눈에 확인
- **확대/축소**: 년 · 분기 · 월 · 주 · 일 단위로 타임라인 확대/축소
- **오늘로 이동 / 전체 맞춤**: 오늘 날짜로 스크롤하거나 전체 이벤트가 화면에 들어오도록 자동 조정
- **검색 & 필터**: 제목/설명 검색, 카테고리별 필터링
- **카테고리 관리**: 카테고리 추가/삭제 및 색상 지정
- **데이터 내보내기/가져오기**: JSON 파일로 백업하거나 불러오기
- **다크 모드**: 라이트/다크 테마 전환 (시스템 설정 자동 감지)
- **로컬 저장**: 브라우저 `localStorage`에 자동 저장되어 새로고침해도 데이터 유지

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

```bash
# 간단한 정적 서버로 실행하고 싶다면 (선택 사항)
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## 파일 구조

```
index.html   # 페이지 구조 및 모달 마크업
styles.css   # 스타일 (라이트/다크 테마 포함)
app.js       # 애플리케이션 로직 (상태관리, 렌더링, 이벤트 처리)
```

## 데이터 형식 (내보내기 JSON)

```json
{
  "events": [
    {
      "id": "ev-...",
      "title": "프로젝트 킥오프",
      "description": "설명 텍스트",
      "category": "cat-work",
      "color": "#4f7cff",
      "start": "2026-01-05",
      "end": ""
    }
  ],
  "categories": [
    { "id": "cat-work", "name": "업무", "color": "#4f7cff" }
  ]
}
```

외부 라이브러리나 프레임워크 없이 순수 HTML/CSS/JavaScript로 작성되어 있어 어떤 정적 호스팅 환경에도 그대로 배포할 수 있습니다.
